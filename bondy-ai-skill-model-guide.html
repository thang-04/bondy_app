1️⃣ Tổng quan hệ thống AI

Bondy sử dụng kiến trúc pipeline cho AI chat. Luồng xử lý:

Client POST /api/ai/chat
  └─ withAuth (JWT Bearer)
  └─ Rate Limit (20 req/min)
  └─ Zod validation (DTO)
  └─ Service Layer (aiChatService)
      ├─ Resolve quota (healing/coach modes)
      └─ Chat Pipeline
          ├─ Load context (matches, emotional state, RAG, history)
          ├─ Build system prompt (mode + skills catalog)
          ├─ Filter tools per mode permissions
          ├─ Safety classifier (keyword → rule → LLM)
          ├─ OpenAI streaming with tool calling
          └─ Post-process (strip reasoning, persist memory)

3️⃣ AI Chat API — POST /api/ai/chat

Endpoint chính cho AI chat. Response là SSE stream (text/event-stream).

Request Body

messages required
Array of { role, content }. Ít nhất 1 message, tối đa 100. Message cuối phải là "role": "user". Mỗi content tối đa 8000 ký tự.
mode
String, kebab-case. Một trong: default | healing | coach | plan | ai-tu-vi. Default: "default".
sessionId
String (optional). Dùng để duy trì context qua nhiều lượt chat.

SSE Stream Response

Mỗi event có format:

event: <type>
data: <json>
Event TypeDataXuất hiện khi
chunkString — text tokenAI đang generate
metadataObject: { tokensUsed, latencyMs, mode, sessionId, classificationRisk?, quota? }Kết thúc stream
errorObject: { message, code }Lỗi trong quá trình stream
done—Stream kết thúc

Parsing SSE stream trong JavaScript

// Xử lý EventSource hoặc fetch stream
const response = await fetch('/api/ai/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json',
             'Authorization': 'Bearer ' + token },
  body: JSON.stringify({ messages, mode })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();
let buffer = '';

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  buffer += decoder.decode(value, { stream: true });

  const lines = buffer.split('\n');
  buffer = lines.pop() || '';

  for (const line of lines) {
    if (line.startsWith('event: ')) {
      currentEvent = line.slice(7);
    } else if (line.startsWith('data: ')) {
      const data = line.slice(6);
      if (currentEvent === 'chunk') {
        // render text token
        appendToChat(JSON.parse(data));
      } else if (currentEvent === 'metadata') {
        // tokensUsed, latencyMs, quota...
        const meta = JSON.parse(data);
        updateMetaDisplay(meta);
      } else if (currentEvent === 'error') {
        showError(JSON.parse(data));
      }
    }
  }
}

🛠️ PHẦN 2 — TẠO MODE & SKILL

7️⃣ Tạo Mode mới

Mode là một file .md trong thư mục src/ai/modes/. File được tự động phát hiện khi server khởi động — không cần đăng ký thủ công.

📁 Đường dẫn
src/ai/modes/<tên-mode>.md

Cấu trúc file mode

---
name: tên-mode          # BẮT BUỘC, kebab-case, vd: "healing", "ai-tu-vi"
description: Mô tả ngắn # BẮT BUỘC, 1-280 ký tự
temperature: 0.7        # 0-2, default 0.7
permissions:
  tools: []               # Danh sách tool names được phép dùng
  canAccessUserMatches: false  # Được load match data?
  canAccessEmotionalState: false # Được load trạng thái cảm xúc?
  canAccessRAG: false        # Được search RAG?
  canPersist: false           # Được ghi DB?
guidance:               # Array các hướng dẫn cho LLM
  - "Hướng dẫn 1"
  - "Hướng dẫn 2"
skills: []               # Skill names mode này dùng
skillPolicy: optional   # disabled | optional | required
---

# System prompt body (markdown)
Bạn là AI có tính cách như thế nào...

## Nguyên tắc
- Nguyên tắc 1
- Nguyên tắc 2

Giải thích các trường

TrườngBắt buộcGiá trịMô tả
name Có kebab-case: ^[a-z][a-z0-9-]*$ Định danh duy nhất của mode. Được client gửi trong field mode.
description Có String, 1-280 ký tự Mô tả ngắn gọn mục đích mode.
temperature Không 0.0 – 2.0 (default: 0.7) Độ sáng tạo của AI. Thấp = deterministic, cao = creative.
permissions.tools Có Array of tool names Danh sách tools được phép gọi. Tool không có trong list sẽ bị filter.
permissions.canAccessUserMatches Có boolean Cho phép AI đọc thông tin match (partner profile, conversation history).
permissions.canAccessEmotionalState Có boolean Cho phép AI đọc trạng thái cảm xúc hiện tại của user.
permissions.canAccessRAG Có boolean Cho phép AI search knowledge base (pgvector + BM25).
permissions.canPersist Có boolean Cho phép AI ghi dữ liệu vào DB (healing messages, feedback, etc).
guidance Không Array of strings Các hướng dẫn bổ sung, được join bằng newline vào system prompt.
skills Không Array of skill names Skills được enable cho mode này. Hiện tại skills là GLOBAL (không filter per mode).
skillPolicy Không disabled | optional | required Chính sách xử lý skill. disabled = không có skill catalog, optional = LLM có thể gọi, required = gợi ý LLM nên dùng skill.

---
name: vent
description: Tâm sự bạn bè thân thiết, không phán xét, không trị liệu

  tools: []
  canAccessUserMatches: false

Bạn là người bạn thân nhất của user — người luôn sẵn sàng lắng nghe mà không phán xét.

## Nguyên tắc
1. **Lắng nghe trước** — để user nói hết, chỉ đặt câu hỏi để khuyến khích họ chia sẻ thêm
2. **Không phán xét** — tuyệt đối không "Sao bạn lại nghĩ vậy?" hay "Đáng lẽ bạn nên..."
3. **Chỉ đưa lời khuyên khi được hỏi** — nếu không, chỉ cần "Mình hiểu", "Nghe khó khăn thật"
4. **Không trị liệu** — nếu thấy dấu hiệu nghiêm trọng, nhẹ nhàng gợi ý tìm chuyên gia
5. **Dùng tiếng Việt thân mật**, có thể dùng emoji 🫂💪

## Phong cách
- Giọng ấm áp, tự nhiên như bạn bè nói chuyện
- Nếu user muốn chuyển chủ đề, theo họ
- Có thể dùng slang nhẹ (mệt mỏi = "mệt vl"), nhưng tôn trọng giới hạn của user
✅ Sau khi tạo file, restart server. Mode "vent" sẽ tự động có sẵn.
Gọi: POST /api/ai/chat với { "mode": "vent", "messages": [...] }
⚠️ Lưu ý
  • Mode mới KHÔNG consume quota trừ khi bạn thêm logic quota trong service layer
  • Nếu mode cần tools mới, phải đăng ký tool trong src/ai/pipeline/get-tools.ts
  • Tên mode phải là kebab-case (chữ thường, dấu gạch ngang)
  • File mode được hot-reload trong dev mode (chokidar watch)

# Nội dung kiến thức (markdown)
Đây là kiến thức chuyên ngành mà AI sẽ đọc khi gọi skill(name="...").

## Có thể dùng markdown
- bullet lists
- **bold**
- ## headings
- và bất kỳ format nào

Cơ chế hoạt động

  1. Discovery: Khi server khởi động, SkillRegistry quét thư mục src/ai/skills/, tìm tất cả folder con chứa SKILL.md → parse frontmatter → cache vào memory.
  2. Catalog: Skills được hiển thị trong system prompt dưới dạng XML block:
<available_skills>
  <skill>
    <name>cung-hoang-dao</name>
    <description>Tra cứu 12 con giáp</description>
  </skill>
  <skill>
    <name>dating-advice</name>
    <description>Gợi ý nhắn tin dating</description>
  </skill>
</available_skills>
  1. Loading: Khi LLM gọi tool skill(name="tên-skill"), nội dung SKILL.md được load và inject vào context.

Ví dụ: Tạo skill "breathing-exercises"

Bước 1: Tạo thư mục và file:

mkdir -p src/ai/skills/breathing-exercises

Bước 2: Tạo file src/ai/skills/breathing-exercises/SKILL.md:

---
name: breathing-exercises
description: "Bài tập thở giúp giảm lo âu, căng thẳng cho user"
---

# Bài tập thở (Breathing Exercises)

## 1. Thở 4-7-8 (Thư giãn sâu)
- **Cách thực hiện:** Hít vào 4 giây → Giữ hơi 7 giây → Thở ra 8 giây
- **Lặp lại:** 4-5 lần
- **Tác dụng:** Giảm lo âu nhanh, dễ ngủ
- **Phù hợp:** Trước khi ngủ, khi đang panic

## 2. Thở bụng (Diaphragmatic Breathing)
- **Cách thực hiện:** Đặt tay lên bụng, hít vào phình bụng, thở ra xẹp bụng
- **Nhịp:** Hít 4s → Thở 6s
- **Thời gian:** 3-5 phút
- **Tác dụng:** Giảm căng thẳng cơ bắp, ổn định nhịp tim

## 3. Thở hộp (Box Breathing)
- **Cách thực hiện:** Hít 4s → Giữ 4s → Thở 4s → Giữ 4s
- **Lặp lại:** 5-10 lần
- **Tác dụng:** Tăng focus, kiểm soát cảm xúc tức thì
- **Phù hợp:** Trước buổi họp, khi cần bình tĩnh nhanh

## 4. Thở luân phiên (Nadi Shodhana)
- **Cách thực hiện:** Bịt lỗ mũi phải, hít vào trái → bịt trái, thở ra phải → đổi bên
- **Thời gian:** 5-10 phút
- **Tác dụng:** Cân bằng hệ thần kinh, giảm anxiety

## Lưu ý an toàn
- Nếu user có bệnh hô hấp (hen suyễn, COPD), khuyên tham khảo bác sĩ trước
- Không tập quá sức — chóng mặt thì dừng lại, thở bình thường
- Kết hợp với nhạc không lời hoặc âm thanh thiên nhiên để tăng hiệu quả

Done! Skill mới tự động có sẵn sau khi restart server. LLM trong các mode có skillPolicy: "optional" hoặc "required" có thể gọi skill(name="breathing-exercises").

Thêm keyword routing (tùy chọn)

Nếu muốn AI tự động detect khi user hỏi về breathing exercises, thêm keywords vào src/ai/skills/router.ts:

// Trong file src/ai/skills/router.ts

// Thêm constant:
const BREATHING_KEYWORDS = [
  'bài tập thở', 'cách thở', 'hít thở',
  'breathing', '4-7-8', 'box breathing',
  'thư giãn', 'bình tĩnh', 'giảm lo âu',
];

// Thêm case trong detectSkillIntent():
if (match(BREATHING_KEYWORDS)) {
  return { skillName: 'breathing-exercises', confidence: 'high' };
}
